# A11y Gate — Spec (council verdict, 2026-11-03)

Source: two-round, five-seat design council in the planning session of 2026-11-03. Event rules: `stranger-builds-fetch-challenge.md`.

## Product
A pre-ship accessibility gate that builder agents hire on Agentverse. A caller sends a URL. It returns automated WCAG 2.2 AA findings, results from a keyboard walk, a verified patch for the fixable issues, the list of criteria that were NOT tested, and a signed "Automated Scan Log".

## Pitch (copy fixed, use verbatim)
- One-liner: "AI agents now build websites. Ours makes sure people can actually use them."
- 30-second version: "AI agents are shipping websites at machine speed, and most of those pages break for people who use screen readers or keyboards. Our agent is a pre-ship gate other agents hire. Send a URL and it scans the page, walks it like a keyboard user, applies fixes that are re-checked to make sure nothing got worse, and returns a signed log of exactly what was tested. It's also honest about what wasn't tested: it never claims a page meets the standard, because automated tools catch less than half of accessibility problems. Builder agents ship better pages, and disabled users get sites that work."
- Demo line: "Before: 'button. button. image.' After: 'Buy now, button. image.'" (image alt text stays with the author; amended 2026-11-03 after the Task 12 review, because the fixer never writes alt text)
- Banned in all copy and output: "compliant", "pass", "certified", "agent-ready".

## Agentverse registration
- Use the **uAgents** option ("Make your agent discoverable on ASI:One Search") for the mailbox lead agent.
- Do not use the adapter options (A2A, LangGraph, CrewAI, Pydantic AI, FastAPI, Custom). They lose the native Payment Protocol and the visible subagent addresses.

## Architecture
- One always-on container (Fly.io) built from the Playwright Python image. It runs one Python process: a uAgents `Bureau` containing 4 agents.
  - `a11y-lead` — `mailbox=True`, Chat Protocol (`publish_manifest=True`), Payment Protocol seller role.
  - `scanner` — axe-core 4.14.0 via Playwright.
  - `walker` — deterministic keyboard checks.
  - `fixer` — deterministic, rule-based patches. No LLM in v1.
- Subagents each have their own address and talk to the lead through typed Models.
- Callers need no integration: a Chat Protocol text message containing a URL is enough. A typed `A11yCheckRequest` protocol is optional.

## Behaviour
- Input: a single public http(s) URL. No crawling. Pasted HTML is not supported in v1; the agent replies asking for a URL.
- Scanner tags: `wcag2a, wcag2aa, wcag21a, wcag21aa, wcag22aa`.
- Walker:
  - Tab traversal up to 50 presses.
  - A trap is 50 presses with no new element and no exit from a non-modal region.
  - Modal containment and return of focus on Escape.
  - Visible focus is checked by a pixel diff of the focused element's box.
  - Logical-order and obscured-focus checks report `needs_review`, never `fail`.
  - Runs with `reduced_motion="reduce"` and a fixed 1280x800 viewport.
- Fixer, deterministic rules only:
  - `html-has-lang` — inserts `lang="en"`.
  - `document-title` — inserts a title taken from the first `h1`, otherwise the hostname.
  - `color-contrast` — adjusts foreground lightness until the ratio is ≥4.5:1 (≥3:1 for large text).
  - `button-name`, `link-name`, `label`, `select-name` — adds `aria-label` from nearby text, placeholder or title, flagged "verify wording".
  - `duplicate-id` — adds a suffix.
  - `image-alt` — no fix; the item is marked `needs_author`.
- Gate: re-scan the patched HTML. Keep a fix only if its rule's violations go down and no new rule ids appear. Each fix is labelled `fixed | not_fixed | regressed`; regressed fixes are dropped.
- Patch allowlist:
  - May only add or modify `alt`, `aria-*`, `role`, `lang`, `for`, `tabindex` (≥ -1), `<title>`, and inline `color` / `background-color`.
  - Rejected: any change to `href`, `src`, `action`, or visible text nodes; any element deletion; any `<script>`; any `on*` attribute; any `javascript:` URL; `aria-hidden` or `display:none` on a focusable or content node.
- Output wording:
  - `automated_status` is `violations_found` or `no_automated_violations_detected`. An error reply, where nothing was scanned, is `not_scanned` (amended 2026-11-03 after the additions review).
  - Never use the words "pass" or "compliant".
  - The disclaimer below is always included.
  - The untested criteria are always listed.
- Receipt ("Automated Scan Log"):
  - ed25519-signed over the input hash, URL, timestamp, engine version, results, untested criteria and disclaimer.
  - States "valid for this exact input at this time only".
  - The public key is published in the README.
- Pricing:
  - Free scan (findings plus a walk summary): 5 per sender address per UTC day.
  - Patch plus receipt costs 0.5 FET via `fet_direct` on the Dorado testnet. It is labelled TEST, and live charging is disabled.
- Safety:
  - Resolve the host and reject private, loopback, link-local, metadata and RFC1918 addresses, re-checked for every request and redirect.
  - Allow http(s) only.
  - 30 s wall-time cap; 2 MB HTML cap.
  - A new browser context per job, with downloads blocked.
  - Store nothing by default; logs hold only rule ids and hashes.

## Disclaimer (verbatim)
"Automated scan result: X violations found across Y tested WCAG 2.2 AA success criteria. Z criteria require manual/human testing and were NOT evaluated. This is not a WCAG conformance determination or legal compliance certification. Suggested code changes are unreviewed and must be checked by a developer before use."

## Additions (agreed 2026-11-03, after the v1 build)
Their purpose is to give builder agents a reason to call the gate repeatedly. Rejected: llms.txt or ai.txt generation (it is SEO, needs crawling and an LLM) and anything framed as "agent-ready".
- **What an AI agent sees.** Every scan includes the page's accessibility tree (a Playwright ARIA snapshot): the same tree screen readers and browser-using AI agents navigate.
  - A free scan shows the tree of the live page.
  - A fix report shows the tree before and after, both taken from the page source with scripts off, so the two are comparable.
  - The tree is page-derived text, so it is quoted in collision-safe fences.
- **Typed protocol for agent callers.** The request is `A11yCheckRequest {url, mode: check|fix}` and the reply is the `Report` model as structured data. The protocol is published in the manifest.
  - It shares the chat path's quota and its 2-job limit.
  - Errors are codes: `bad_request`, `quota_exceeded`, `busy`, `payment_required`.
  - While payment is on, a paid fix still goes through chat and the Payment Protocol.
- **Recheck.** A scan from the same sender of the same URL shows what changed since that sender's previous scan: automated issues A → B, G no longer detected, N new.
  - Kept in memory only, as hashes: sha256 of sender and URL, and sha256 of each rule and selector pair. This keeps the "store nothing, hashes only" rule.
  - `recheck <url>` is accepted as a scan.
