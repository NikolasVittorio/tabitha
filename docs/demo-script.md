# Demo scripts

Wording rules: never claim the page meets a standard. The counter reads "Automated issues N → M (image alt text needs the author)" and the next line reads "N criteria need human review" (N and M are measured from the actual smoke run; fill the placeholders from it, do not invent numbers). Screen-reader audio is pre-recorded with NVDA, never live. Payments are TEST FET on Dorado.

Demo page: `https://<gh-pages>/demo/broken.html`. Demo line: "Before: 'button. button. image.' After: 'Buy now, button. image.'"

## Walkthrough (3 to 5 minutes)

1. **Problem and who it is for (0:00-0:30).** Agents ship pages at machine speed; unlabelled buttons, missing alt text, low contrast and keyboard traps reach screen reader and keyboard users. Expected callers are builder agents; people can chat with it too.
2. **Architecture (0:30-1:15).** One uAgents Bureau, four agents: lead (Chat and Payment Protocol, mailbox), scanner (axe-core 4.14.0 in Playwright), walker (keyboard walk, up to 50 Tab presses), fixer (rules only, no LLM). Show the four addresses.
3. **Step 1: broken page (1:15-1:45).** Open `demo/broken.html`. [AUDIO: before]
4. **Step 2: focus path (1:45-2:15).** Run `check <url>`. Show the focus-path overlay with focus trapped in the modal. Mention logical order and obscured focus are reported as needing review, never as failures.
5. **Step 3: patch and counter (2:15-3:00).** Run `python -m agents.demo_buyer <url>`. Show the payment request, the memo equal to the reference, the commit. Then the patch and "Automated issues N → M (image alt text needs the author)", and "N criteria need human review". Show one fix labelled "verify wording" and one `needs_author` item (image alt text).
6. **Step 4: audio after (3:00-3:20).** [AUDIO: after]
7. **Step 5: receipt and payment (3:20-4:00).** Show the Automated Scan Log, verify the signature against the key published in the README, show the Dorado explorer tx and the reference. State it is valid for that exact input at that time only.
8. **Honest limits (4:00-4:30).** Show the disclaimer and the untested criteria. Automated coverage is roughly 40% at best (the GOV.UK GDS audit's best tool). Show `check http://169.254.169.254/` refused, and `check https://example.com` returning no automated violations with the same disclaimer.
9. **Close (4:30-4:45).** Address, repo, badges, how a builder agent calls us.
